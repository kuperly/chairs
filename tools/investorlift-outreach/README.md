# InvestorLift wholesaler outreach

כלי שרץ **על המחשב שלך** (InvestorLift חוסם גישה משרתי ענן) ומשתמש בדפדפן אמיתי שבו אתה מחובר לחשבון שלך.

## התקנה (פעם אחת)
```bash
cd tools/investorlift-outreach
npm install
npx playwright install chromium
npm run login        # נפתח דפדפן, מתחברים ידנית ל-InvestorLift, ואז Enter
```

## הגדרות
- `config/buybox.json` – מדינות / ערים / מיקודים, טווח מחירים, סוג נכס, מינימום חדרים, ומספר העסקאות המינימלי שהולסלר צריך שיהיו לו ב-buy box.
- `config/message.txt` – תבנית ההודעה. משתנים: `{{contact}}`, `{{company}}`, `{{markets}}`, `{{example_address}}`, `{{buybox_summary}}`.
- `config/settings.json` – מגבלה יומית, השהיות בין הודעות, ו-selectors של כפתור יצירת הקשר / תיבת הטקסט / כפתור השליחה.

## תהליך
1. `npm run collect` – פותח את ה-marketplace. מגדירים פילטרים, לוחצים Enter, והסקריפט גולל ושומר את כל תגובות ה-API (JSON) שהאתר טוען, לתיקייה `data/raw/`.
2. `npm run inspect` – מציג את מבנה הנתונים שנאספו ודוגמאות לעסקאות שזוהו. אם שדות יוצאים ריקים, מוסיפים את שמות השדות האמיתיים ב-`src/extract.mjs`.
3. `npm run match` – מסנן לפי ה-buy box ומקבץ לפי הולסלר. הפלט: `data/wholesalers.csv` (ממוין לפי מספר העסקאות המתאימות) ו-`data/matched-deals.csv`.
4. `npm run send -- --dry-run` – מציג את כל ההודעות בלי לשלוח.
5. `npm run send` – פותח כל עסקה, ממלא את ההודעה ומחכה לאישור שלך (y/n/q) לפני כל שליחה.
   `npm run send -- --auto` – שליחה בלי אישור, עם מגבלה יומית והשהיה אקראית בין הודעות.

ההיסטוריה נשמרת ב-`data/sent.json`, כך שאף הולסלר לא מקבל הודעה פעמיים.

## חשוב
- סביר שתנאי השימוש של InvestorLift אוסרים איסוף נתונים אוטומטי והודעות אוטומטיות. שימוש כזה עלול לגרום לחסימת החשבון. כדאי לשמור על נפח נמוך (ברירת המחדל: 20 הודעות ביום) ולהעדיף את מצב האישור הידני.
- את ה-CSV של ההולסלרים אפשר להשתמש בו גם לפנייה מחוץ לפלטפורמה (מייל, טלפון, הצטרפות לרשימת הקונים באתר שלהם), ולרוב זה הערוץ האפקטיבי יותר.

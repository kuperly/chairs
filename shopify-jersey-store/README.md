# חנות חולצות כדורגל וכדורסל – Shopify

תבנית Shopify מותאמת אישית (Online Store 2.0) בעברית ו-RTL, עם סקריפט שמקים את מבנה החנות.
האתר בנוי באותו מבנה ועם אותן יכולות כמו אתר הרפרנס: ליגות, נבחרות, רטרו, ילדים, NBA, הדפסת שם ומספר, מעקב הזמנה.
העיצוב, הטקסטים והקוד נכתבו מחדש ואינם העתק של האתר.

```
shopify-jersey-store/
├── theme/                  ← התבנית (מעלים ל-Shopify)
│   ├── layout/             theme.liquid, password.liquid
│   ├── sections/           header, footer, hero, product, collection, cart drawer ...
│   ├── snippets/           product-card, price, facets, cart-line, icon ...
│   ├── templates/          JSON templates (בית, מוצר, קולקציה, עגלה, מעקב הזמנה ...)
│   ├── assets/             base.css, theme.js (ללא תלויות)
│   ├── config/             הגדרות תבנית (צבעים, גופנים, הדפסה, וואטסאפ ...)
│   └── locales/            he.default.json, en.json
├── scripts/
│   ├── setup-store.mjs     מקים קולקציות, תפריטים, עמודים ומוצרי תוספת דרך Admin API
│   └── store-structure.mjs מבנה החנות (קולקציות, תפריט, עמודים) – לעריכה
└── data/products-template.csv  תבנית לייבוא מוצרים בכמויות
```

## 2. הקמה צעד אחר צעד

### א. הגדרות בסיס באדמין
1. **Settings → Store details:** מטבע **ILS (₪)**, אזור זמן ירושלים.
2. **Settings → Languages:** להוסיף עברית ולהגדיר אותה כשפת ברירת מחדל. אנגלית אפשר להשאיר כשפה נוספת.
3. **Settings → Markets:** ישראל כשוק ראשי. אם רוצים, להוסיף גם ארה"ב או שווקים אחרים. בורר המדינות בפוטר יופיע אוטומטית.
4. **Settings → Taxes:** "All prices include tax" (מע"מ כלול במחיר).
5. **Settings → Customer accounts:** מומלץ "Customer accounts" (החדש): כניסה עם קוד חד-פעמי במייל, ובו הלקוח רואה את ההזמנות ואת מספרי המעקב.
6. **Settings → Checkout:** לבקש מספר טלפון (חשוב לשליח), ולהפעיל שמירת עגלות נטושות.

### ב. העלאת התבנית
**אפשרות 1: קובץ ZIP**
```bash
cd shopify-jersey-store/theme && zip -r ../kit-room-theme.zip . && cd ..
```
Online Store → Themes → Add theme → Upload zip file → Publish.

**אפשרות 2: Shopify CLI** (מומלץ לפיתוח)
```bash
npm i -g @shopify/cli
cd shopify-jersey-store/theme
shopify theme dev --store your-store.myshopify.com     # תצוגה מקדימה חיה
shopify theme push --unpublished --store your-store.myshopify.com
shopify theme check                                    # בדיקת איכות (עובר ללא שגיאות)
```

### ג. הרצת סקריפט ההקמה
הסקריפט יוצר:
- 30 קולקציות חכמות לפי תגיות
- תפריט ראשי עם מגה-מניו, ושני תפריטי פוטר
- עמודים: מעקב הזמנה, צור קשר, טבלת מידות, משלוחים והחזרות
- 2 מוצרי תוספת נסתרים: הדפסת שם ומספר (₪40) ופאץ' (₪20)
- עם `--with-samples`: גם 8 מוצרי דוגמה, בלי תמונות

1. יוצרים אפליקציה ב-[Dev Dashboard](https://dev.shopify.com) ומתקינים אותה על החנות, עם ה-scopes:
   `write_products, write_publications, write_online_store_pages, write_online_store_navigation`
2. מריצים:
```bash
cd shopify-jersey-store
# עם Client ID + Secret של האפליקציה:
SHOPIFY_STORE=your-store.myshopify.com SHOPIFY_CLIENT_ID=xxx SHOPIFY_CLIENT_SECRET=yyy \
  node scripts/setup-store.mjs --dry-run          # קודם לבדוק מה ייווצר
SHOPIFY_STORE=your-store.myshopify.com SHOPIFY_CLIENT_ID=xxx SHOPIFY_CLIENT_SECRET=yyy \
  node scripts/setup-store.mjs --with-samples
# או עם Admin API access token קיים:
SHOPIFY_STORE=... SHOPIFY_ADMIN_TOKEN=shpat_xxx node scripts/setup-store.mjs
```
מותר להריץ את הסקריפט שוב ושוב. מה שכבר קיים לא נוצר פעמיים, והתפריטים מתעדכנים.
כדי לשנות קולקציות או את התפריט, עורכים את `scripts/store-structure.mjs`.

### ד. הגדרות בעורך התבנית (Customize)
- **Theme settings → הדפסת שם ומספר:** בוחרים את המוצרים "הדפסת שם ומספר" ו"פאץ' ליגה" ומעדכנים את תוויות המחיר.
- **Theme settings → עמוד מוצר:** בוחרים את העמוד "טבלת מידות".
- **Theme settings → רשתות חברתיות:** מספר וואטסאפ (מציג כפתור צף), Instagram, Facebook ו-TikTok.
- **Header:** מעלים לוגו.
- **דף הבית:** מעלים תמונות לבאנר, ל"תמונה עם טקסט" ולאריחי הליגות (סמלים), ומעדכנים ביקורות.
- **Search & Discovery → Filters:** מוסיפים פילטרים: מידה, סוג מוצר, מותג, זמינות ומחיר.

### ה. לפני השקה
- [ ] תשלום ניסיון מלא (Bogus gateway, ואז כרטיס אמיתי + ביטול)
- [ ] תעריפי משלוח וסף משלוח חינם, שתואם להגדרת "סף משלוח חינם" בעגלה הצדדית
- [ ] התראות במייל ובעברית: Settings → Notifications
- [ ] מדיניות ותקנון, הצהרת נגישות

## 3. ניהול מוצרים

כל קולקציה היא **חכמה**: מוצר נכנס אליה אוטומטית לפי **תגיות**. אין צורך לשייך מוצרים ידנית.

| תגית | נכנס ל... |
|---|---|
| `premier-league` / `la-liga` / `serie-a` / `bundesliga` / `ligue-1` / `israeli-league` / `rest-of-world` | הליגה המתאימה |
| `national-team` | נבחרות |
| `world-cup-2026` | מונדיאל 2026 |
| `retro` (+ תגית ליגה) | רטרו, ורטרו של הליגה |
| `kids` | ילדים |
| `training` / `pre-match` / `tracksuit` / `casual-tee` / `ball` | אימון / חימום / אימוניות / טישרטים / כדורים |
| `basketball` + `nba` + `jersey` / `shorts` / `tee` | כדורסל ו-NBA |
| `new` | חדש במלאי, ותגית "חדש" על הכרטיס |
| `personalizable` | מציג בעמוד המוצר שדות **שם + מספר** (בתוספת תשלום) |
| `patch-available` | מציג אפשרות **פאץ' ליגה** |
| `home` / `away` / `third` / `goalkeeper` | לשימוש בפילטרים |

- **הנמכרים ביותר** ו**כל המוצרים** כוללים אוטומטית את כל המוצרים חוץ ממוצרי התוספת.
- **מבצעים:** כל מוצר עם "Compare-at price" גבוה מהמחיר.
- **אפשרות "מידה":** אם קוראים לאפשרות "מידה" או "Size", יופיע לידה הקישור "טבלת מידות".
- **ייבוא בכמויות:** `data/products-template.csv` → Products → Import. אם הייבוא דוחה את הכותרות, מורידים את התבנית העדכנית מחלון הייבוא ומעתיקים אליה את הנתונים.

### איך עובדת הדפסת השם והמספר
1. הלקוח בוחר מידה, ממלא שם ומספר ומסמן פאץ'.
2. לעגלה נכנסים החולצה, עם השם והמספר כ-line item properties, **ומוצר התוספת בתשלום** המקושר אליה.
3. שינוי כמות או הסרה של החולצה בעגלה מעדכנים גם את התוספות המקושרות.
4. בהזמנה באדמין, על שורת החולצה מופיע `שם: MESSI` / `מספר: 10`, ועל שורת התוספת מופיע לאיזו חולצה היא שייכת.

## 4. ניהול הזמנות (מובנה ב-Shopify)

כל ניהול ההזמנות נעשה באדמין של Shopify, במחשב או באפליקציית **Shopify** בנייד:

| פעולה | איפה |
|---|---|
| רשימת הזמנות, סינון לפי סטטוס תשלום ומשלוח | Orders |
| **Fulfill** + הזנת מספר מעקב, והלקוח מקבל מייל אוטומטי | Orders → הזמנה → Fulfill item |
| הדפסת תוויות ותעודות משלוח | Orders → Print packing slips (או אפליקציית השליחויות) |
| עריכת הזמנה (החלפת מידה, הוספת פריט) | Orders → Edit |
| החזרות, החלפות וזיכויים | Orders → Return / Refund |
| הזמנה ידנית (וואטסאפ או טלפון) + שליחת לינק תשלום | Orders → Drafts |
| עגלות נטושות + מייל תזכורת | Orders → Abandoned checkouts |
| מלאי לפי מידה | Products → Inventory |
| לקוחות, היסטוריה ותגיות | Customers |
| קופונים ומבצעים (למשל "2 חולצות ב-₪399") | Discounts |
| דוחות מכירות | Analytics |

**אוטומציות מומלצות ב-Shopify Flow:**
- הזמנה עם הדפסה אישית (line item property "שם" או "מספר") → תגית `needs-printing` והתראה במייל.
- מלאי של וריאנט ירד מתחת ל-3 → התראה.
- לקוח עם 3 הזמנות ומעלה → תגית `VIP`.

**הלקוח:** מקבל מייל אישור, ואחר כך מייל משלוח עם מספר מעקב. בעמוד "מעקב הזמנה" (`/pages/order-tracking`) הוא נכנס לחשבון ורואה את הסטטוס. אפשר להחליף את העמוד באפליקציית מעקב דרך בלוק אפליקציה.

## 5. מה כלול בתבנית

- **כותרת עליונה:** פס הודעות מתחלף, לוגו, מגה-מניו עד 3 רמות, חיפוש, חשבון, עגלה עם מונה, תפריט מובייל.
- **דף הבית (הכל ניתן לעריכה ולסידור מחדש):** פס אמון, באנר עם דירוג, אריחי ליגות, קולקציות בסליידר, מבצע מוגבל, ביקורות, חיפוש שחקן או קבוצה עם חיפושים פופולריים.
- **קולקציה:** פילטרים (Search & Discovery), מיון, עמודים, תגיות מבצע/חדש/אזל, תמונה שנייה במעבר עכבר.
- **מוצר:** גלריה, בחירת מידה עם סימון מידות שאזלו, שם ומספר, פאץ', טבלת מידות בחלון, כפתורי תשלום מהיר, אקורדיונים, המלצות מוצרים ו-SEO (structured data).
- **עגלה:** עגלה צדדית (AJAX) עם פס התקדמות למשלוח חינם, ועמוד עגלה מלא עם הערה להזמנה.
- **פוטר:** תפריטים, ניוזלטר, רשתות חברתיות, בורר מדינה ומטבע, אמצעי תשלום, מדיניות.
- **נוסף:** כפתור וואטסאפ צף, עמוד מעקב הזמנה, צור קשר, 404, בלוג, כרטיס מתנה ועמוד סיסמה.
- **טכני:** בלי jQuery ובלי תלויות, גופנים מה-CDN של Shopify, `shopify theme check` עובר ללא שגיאות.
